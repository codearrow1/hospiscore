## Important Details
- Stack: Next.js 16.3.0, React 19.2.8, TypeScript 5, Tailwind v4 (App Router, no `src/`, `@/*` alias), Vitest + tsx.
- Project root: `C:\Users\Asus\Documents\pms score app` (folder has spaces; cmds quote/workdir).
- Dev server on **port 3090**, detached via `npm run dev -- --port 3090`, logs in `dev-server.log`; currently running. Stop with `Stop-Process -Id <pid> -Force`.
- Live data via `GOOGLE_PLACES_API_KEY`; demo mode (seeded 10 properties) when unset. Review provider: demo|stayapi|apify. Cache: memory|redis. Snapshot: `npm run snapshot` → `var/scores` (10 snapshots exist).
- Scoring weights (13): ratingQuality .22, reviewVolume .13, reviewVelocity .08, responseRate .06, platformDiversity .05, guestExperience .16, presence .08, amenities/visualContent .05, sustainability .04, accessibility/directBookings .03, brandTrust .02. Grades: 85+ Excellent, 70–84 Good, 50–69 Fair, <50 Poor. Missing signals = neutral 50 + `sourced:false`. Result has `dataCompleteness`.
- 10 platforms: google, booking, tripadvisor, expedia, airbnb, agoda, hotels (Hotels.com), vrbo, hostelworld, trip (Trip.com) — in `TOTAL_PLATFORMS`/`PLATFORM_NAMES`/`OTAS`.
- Next.js 16 gotchas: route params async, text interpolation renders `Claim <!-- -->` (fine), solid/verbose `import("redis")` statically fails.
- 96 tests pass across 19 files (incl. `lib/demo.test.ts`, `lib/modules.test.ts`, `lib/featurePages.test.ts`, `lib/reportRequest.test.ts`, `lib/leads.test.ts`); types+lint+build clean (verified 07 Aug).- Marketing is server components where possible; only `BookDemoForm`, `ContactForm`, `PropertySearch`, `RealtimeFeed`, `PricingCalculator`, `ReportEmailForm`, `LeadStatusControl`, `Reveal`, `CountUp`, `ProductTour`, `ScrollProgress`, `BackToTop`, `SpotlightCard`, `RotatingWords`, `TiltCard` and `Faq` are `"use client"`. `Marquee` and `PageHero` are server-safe (pure CSS animation). Demo/contact requests persist via the shared `lib/db.ts` facade → `DataFile.demoRequests`; score-report email requests → `DataFile.reportRequests` (file or SQLite).
- Internal leads (`/account/leads`) gated by `ADMIN_EMAILS` env (comma-separated, lowercased). Dev server currently runs with `ADMIN_EMAILS=owner@hospios.dev`. Admin flag surfaces to the client via `/api/auth/me` (`isAdmin`). Lead status lives on `DemoRequest`/`ReportRequest` as optional `status?` (new|contacted|won|closed); client-safe constants in `lib/accountTypes.ts`.
- Theme is **forced dark**: `app/layout.tsx` puts `dark` on `<html>` + Inter font; `app/globals.css` uses `@custom-variant dark (&:where(.dark, .dark *));` with `.dark` tokens (no `prefers-color-scheme` media query).
